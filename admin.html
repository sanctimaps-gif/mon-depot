Connexion

Cette console modifie le site pour de vrai : ce que vous enregistrez ici est publié et visible par tous les visiteurs, en une minute environ.

Votre compte, c'est votre compte GitHub. Le site n'a pas de serveur : il n'y a donc pas de mot de passe à stocker quelque part — ce serait de toute façon visible dans le code de la page. À la place, vous collez une clé d'accès créée depuis votre compte GitHub. Elle reste dans ce navigateur et n'est envoyée qu'à GitHub.

Comment créer cette clé (une seule fois, 2 minutes)
  1. Sur GitHub : Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Nom : Site du bar. Expiration : au choix (90 jours par exemple).
  3. Repository access → Only select repositories → choisir mon-depot.
  4. Permissions → Repository permissions → Contents : passer à Read and write. Ne rien cocher d'autre.
  5. Générer, copier la clé, la coller ci-dessus. GitHub ne la réaffichera plus.

La clé ne donne accès qu'à ce dépôt, et seulement à ses fichiers. En cas de doute, révoquez-la sur GitHub : elle cesse aussitôt de fonctionner.

Sur un ordinateur partagé, décochez « rester connecté » : la clé sera oubliée à la fermeture de l'onglet.

Réglages

Dès qu'elle est renseignée, le formulaire de contact du site l'utilise : le visiteur envoie son message depuis sa messagerie. Laissée vide, le formulaire renvoie vers le téléphone.

Utilisé par le bouton « Appeler ».

Elle disparaît toute seule dès qu'au moins un prix est renseigné.

La carte

Laissez un prix vide pour ne pas l'afficher. Une ligne sans nom est ignorée. L'ordre à l'écran est celui du site.

Événements
